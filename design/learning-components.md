## 1. Дизайн-токены (Figma Variables)

Токены собраны из значений, которые реально использовались в вайрфреймах (серая шкала zinc и красный для ошибок). Всего **68 переменных** в 5 коллекциях. Экспорт в JSON: `design/tokens.json` (формат W3C Design Tokens).

| Коллекция | Переменных | Содержимое |
|---|---|---|
| **Colors** | 33 | `surface/*`, `border/*`, `text/*`, `action/primary`, `status/*` (error, success, warning, info), 8 акцентов (+ `-subtle` для каждого) |
| **Typography** | 15 | `font/family/base` = Inter; веса 400, 500, 600; размеры `xs`…`4xl` (11–28 px); `line-height/tight`, `line-height/normal` |
| **Spacing** | 10 | `space/0, 2, 4, 8, 12, 16, 20, 24, 32, 48` |
| **Radius** | 6 | `xs 4`, `sm 6`, `md 8`, `lg 12`, `xl 16`, `full 999` |
| **Breakpoints** | 4 | `mobile 360`, `tablet 768`, `desktop 1280`, `wide 1440` |

| orange | `#ea580c` | `#ffedd5` |

### Текстовые стили

`Text/Body` (14 Regular), `Text/Label` (14 Medium), `Text/Label Small` (12 Medium), `Text/Caption` (12 Regular), `Text/Title` (18 Semi Bold), `Text/Code` (12, Roboto Mono). Размер шрифта в стилях привязан к переменным `font/size/*`.

### Привязка в вайрфреймах

Цвета заливок и обводок, радиусы, отступы (gap и padding), размер и семейство шрифта в вайрфреймах привязаны к переменным там, где значение точно совпадает с токеном.

Значения вне шкалы не привязывались: радиусы 2, 3, 10 и отступы 3, 10, 14.

## 4. Где компоненты применены в проекте

Компоненты заменяли вручную нарисованные элементы в вайрфреймах (экземпляры привязаны к главным компонентам):

| Компонент | Экземпляров | Где |
|---|---|---|
| **Button** | 94 | Primary и Secondary во всех разделах |
| **Badge** (Neutral) | 63 | «Серия», «XP», «Не начато», теги тем и т. п. |
| **Input** | 4 | Поля в разделе «Системные экраны» |

**Не применены** (нарисованы вручную как раньше): Question Card, Answer Option, True False, Answer Feedback, Code Block, Table, Tabs, Toast, Modal, Skeleton.

### Намеренно оставлено как есть

- клавиши калькулятора и кнопки-иконки со стрелками;
- «вкладки» профиля («Достижения», «Лига», «Косметика», «Настройки»);
- шаги «1 Что такое…», чипы «ТГО», ссылки-чипы «Урок: …»;
- красная кнопка с обводкой «Сбросить прогресс» (в библиотеке нет такого варианта);
- меню навигации и переключатели «Светлая / Тёмная / Системная».

### Что изменилось после замены

- Кнопки выше на 2 px (41 вместо 39), текст 14 px вместо 13.
- У тёмных кнопок исчезла дополнительная обводка.
- Подписи полей стали крупнее (14 px Medium вместо 11 px).
- Текст в полях по умолчанию серый (как подсказка), даже где в макете было значение.

## 5. Ограничения

- **Тёмной темы нет.** Бесплатный тариф Figma допускает один режим в коллекции. На платном можно добавить режим Dark.
- **Skeleton статичный:** анимацию мерцания Figma через API не поддерживает.
- **Иконок в компонентах нет:** иконок в файле пока нет.
- **Hover у Danger** использует `accent/red`, отдельного токена «тёмно-красный» нет.
- **Тени** у Toast и Modal заданы вручную, тени как токена нет.
- **Вес шрифта** создан как переменная, но к текстам не привязан.
- **Брейкпоинты и 8 акцентов** созданы как токены, но в макетах используются только акценты внутри Badge.
- **Code Block:** код редактируется прямо в тексте, это не свойство компонента.
- **Table** — один готовый компонент, не конструктор. Для новых строк копируй существующие.

## 6. Как проверить в Figma

1. **Переменные:** снять выделение → правая панель → **Open variables** → список коллекций слева.
2. **Компоненты:** страница **Components**, либо панель **Assets** (иконка с четырьмя квадратами).
3. **Где используется компонент:** выбрать главный компонент → **Go to instances**.
4. **Привязка токена:** выбрать слой, в Fill/Stroke вместо hex должно быть имя переменной, например `color/action/primary`.
5. **История изменений:** **File → Show version history**.

3. На платном тарифе Figma добавить режим Dark в коллекцию Colors.
4. Привязать веса шрифта и подключить брейкпоинты к адаптивным макетам.
5. Подключить `design/tokens.json` в репозиторий (PR, CI, staging по критерию готовности A-03).
