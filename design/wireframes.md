# A-02. Вайрфреймы

Серые вайрфреймы (десктоп, 1440 × 900) по [карте экранов](screen-map.md).

Figma: https://www.figma.com/design/ZU8fAgWMh6v28jMrWiiIQj

Коды экранов совпадают с картой. Каждая секция называется по группе, над каждым экраном подписаны путь и особенности.

| Группа | Экраны | Статус |
|---|---|---|
| X · Системные | X1 Первый вход, X2 Настройки, X3 404 | готово |
| H · Главная | H1 | готово |
| L · Учёба | L1 Предметы, L2 Темы, L3 Урок | готово |
| T · Тесты | T1 Тест, T2 Итог, T3 Разбор | готово |
| P · Практика | P1 Хаб, P2 Ошибки, P3 Карта дыр, P4 Смешанный | готово |
| I · ИИ | I1 Чат, I2 История | готово |
| K · Пробный КТ | K0–K5 | готово |
| M · Профиль | M1 Профиль, M2 Достижения, M3 Лига, M4 Косметика | готово |
| N · План и новости | N1 План, N2 Новости | готово |
| O · Общие окна | O1 Поиск, O2 Тосты, O3 Достижение, O4 Ключ, O5 Подтверждение, O6 Калькулятор, лист состояний | не сделано |
