# A-02. Вайрфреймы

Серые вайрфреймы по [карте экранов](screen-map.md): ноутбук (1440 × 900) и телефон (360 × 800).

Figma: https://www.figma.com/design/Zj2R4SqYS4pS2BYmElCfWz

Коды экранов совпадают с картой. Каждая секция названа по группе, над каждым экраном подписаны путь и особенности.

| Секция | Экраны |
|---|---|
| X · Системные | X1 Первый вход, X2 Настройки, X3 404 |
| H · Главная | H1 |
| L · Учёба | L1 Предметы, L2 Темы, L3 Урок |
| T · Тесты | T1 Тест, T2 Итог, T3 Разбор |
| P · Практика | P1 Хаб, P2 Ошибки, P3 Карта дыр, P4 Смешанный |
| I · ИИ-наставник | I1 Чат, I2 История |
| K · Пробный КТ | K0 История, K1 Направление, K2 Инструктаж, K3 Экзамен, K4 Итог, K5 Разбор |
| M · Мотивация и профиль | M1 Профиль, M2 Достижения, M3 Лига, M4 Косметика |
| N · План и новости | N1 План, N2 Новости |
| O · Общие окна и состояния | O1 Поиск, O2 Тосты, O3 Достижение, O4 Ключ, O5 Подтверждение, O6 Калькулятор, лист состояний |
| Мобильные · 360 × 800 | Mo1 Главная, Mo2 Урок, Mo3 Тест, Mo4 Экзамен КТ, Mo5 ИИ-чат (нижний лист), Mo6 Карта дыр, Mo7 Профиль, Mo8 План |
| Меню · закрытое состояние | Ноутбук: свёрнутая панель с иконками (72 px). Телефон: кнопка ≡ и нижние вкладки |

Остальные мобильные экраны будут делаться в A-13 по утверждённым ноутбучным макетам.
